# かなり · 일본어 플릭 키보드 연습

일본어 12키 플릭 키보드에 익숙해지기 위한 모바일 웹앱입니다. React, TypeScript, Vite로 만들었으며 별도 서버나 환경 변수 없이 Vercel에 배포할 수 있습니다.

## 실행

Node.js 22 (22.12 이상)와 npm을 사용합니다.

```sh
npm ci
npm run dev
```

로컬 주소는 http://localhost:5173 입니다. 같은 Wi-Fi의 휴대폰에서는 Vite가 출력하는 Network 주소를 열 수 있습니다. 휴대폰의 **일본어 가나 12키 키보드**를 사용합니다. 앱 안에서 키보드 준비 방법을 확인할 수 있습니다.

```sh
npm test       # 입력 판정, 콘텐츠 무결성, 세션 구성, 저장·연속 기록 검사
npm run build # TypeScript 검사와 프로덕션 빌드
npm run preview
```

## 연습 종류

- **한 글자**: 기본 히라가나 46자, 탁음 20자, 반탁음 5자, 작은 글자 10자. 행별 선택 또는 전체 81자 랜덤.
- **단어 400개**: 음식, 자연, 집과 물건, 사람과 몸, 장소와 여행, 시간과 일상, 동작, 상태와 느낌, 취미와 배움, 동물. 전체 또는 주제별 랜덤.
- **문장 160개**: short 60개, middle 55개, long 45개.
- **장문 12편**: 각각 4문장으로 구성된 창작 일상 이야기. 한 글을 문장별로 이어서 입력하며 전체 원문과 번역도 펼쳐 볼 수 있습니다.

단어·문장·장문은 **총 572개**이며 한 글자 연습은 별도입니다. 모든 항목에 한국어·영어 뜻이 있고, 후리가나는 기본으로 켜져 있습니다. 설정에서 후리가나, 뜻 언어, 문제 수(5/10/20), 일일 목표를 변경할 수 있습니다.

정답은 한자, 히라가나, 혼합 변환을 허용합니다. 가타카나·반각 입력은 히라가나로 정규화하며 공백과 일반 문장부호는 생략할 수 있습니다. 작은 글자, 장음, 조사는 구별합니다. 예를 들어 「今日は学校へ行きます。」는 「きょうはがっこうへいきます」, 「今日はがっこうへ行きます」도 정답입니다.

## 모바일 입력과 레이아웃

- `visualViewport`의 높이와 위치를 반영해 소프트웨어 키보드 위의 보이는 영역에 연습 화면을 맞춥니다. `dvh`는 미지원 환경의 대체 높이로 사용합니다.
- 문제 영역은 독립적으로 스크롤되고 입력창과 확인 버튼은 화면 아래에 유지됩니다. 장문을 한 문장씩 표시해 화면 부담을 줄입니다.
- `safe-area-inset-*`, 작은 높이용 레이아웃, 16px 이상의 입력 글자 크기, 화면 확대, reduced-motion을 고려했습니다.
- IME 조합 중에는 정답을 판정하지 않습니다. 변환 확정용 Enter와 답안 확인용 Enter가 겹치지 않도록 조합 직후의 키 이벤트도 보호합니다. ‘확인’을 직접 눌러도 됩니다.
- 다음 문제로 이동할 때 입력창의 포커스를 유지합니다. 자체 가상 키보드를 띄우지 않습니다.

데스크톱 브라우저의 화면 축소는 실제 iOS/Android IME와 같지 않습니다. 배포 후 실제 Safari·Chrome에서 키보드 열기, 변환 확정, 다음 문제 이동, 가로 전환, 작은 화면을 확인하는 것이 좋습니다.

## 기록과 개인정보

설정과 최근 500회 완료 기록은 `localStorage`의 `kanari:v1`에 저장됩니다. 로그인, 서버 전송, 분석 추적 기능은 없습니다. 브라우저 데이터를 삭제하면 기록이 사라집니다. 저장이 차단되거나 공간이 부족하면 안내를 표시하고 연습은 계속할 수 있습니다. 진행 중 나간 세션은 기록되지 않습니다.

정확도는 `정답 수 / (확인 횟수 + 건너뛴 수)`입니다. 입력 속도는 `정답의 정규화된 히라가나 읽기 글자 수 / 첫 입력부터 종료까지의 분`이며, 변환 대기와 다음 문제로 이동하는 시간도 포함합니다. 일일 목표와 연속 일수는 사용자 기기의 현지 날짜를 기준으로 합니다.

## Vercel 배포

1. Vercel의 **Add New → Project**에서 `5tarlight/japanese-flick-keyboard` 저장소를 가져옵니다.
2. Framework Preset은 **Vite**, Build Command는 `npm run build`, Output Directory는 `dist`입니다. `vercel.json`에 설정되어 있습니다.
3. 환경 변수는 필요 없습니다. **Deploy**를 누르면 됩니다.

이 프로젝트는 단일 URL 내 화면 전환을 사용해 별도의 SPA rewrite 설정이 필요 없습니다. 실제 배포는 사용자의 Vercel 프로젝트 연결 후 진행합니다.

참고: [Vercel의 Vite 배포 안내](https://vercel.com/docs/frameworks/frontend/vite), [MDN VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport), [MDN compositionend](https://developer.mozilla.org/en-US/docs/Web/API/Element/compositionend_event).
